## 접근 방식 비교

### 방식 1: 클라이언트 컴포넌트 (현재 구현)

**구현:**
```typescript
'use client';
import { createBrowserSupabaseClient } from '@/lib/supabase/client';

export function SignUpForm() {
  const supabase = createBrowserSupabaseClient();
  await supabase.auth.signUp({ email, password });
}
```

**장점:**
- ✅ **Supabase 권장 방식**: Supabase 공식 문서의 권장 패턴
- ✅ **즉각적인 피드백**: 클라이언트에서 바로 에러 처리
- ✅ **세션 관리 자동**: Supabase가 쿠키 자동 관리
- ✅ **OAuth 호환**: OAuth 플로우와 일관성 유지
- ✅ **리다이렉트 용이**: `onAuthStateChange`로 실시간 처리
- ✅ **간단한 구현**: 추가 서버 로직 불필요

**단점:**
- ⚠️ **서버 검증 부족**: 클라이언트에서만 검증 (하지만 Supabase가 서버에서 검증)
- ⚠️ **추가 비즈니스 로직 어려움**: 회원가입 후 추가 작업이 복잡할 수 있음

### 방식 2: Server Action (5.0.md 계획)

**구현:**
```typescript
'use server';
import { createServerSupabaseClient } from '@/lib/supabase/server';
import { redirect } from 'next/navigation';

export async function signUpWithEmail(formData: FormData) {
  const supabase = await createServerSupabaseClient();
  const { error } = await supabase.auth.signUp({
    email: formData.get('email'),
    password: formData.get('password'),
  });
  
  if (error) {
    return { error: error.message };
  }
  
  redirect('/dashboard');
}
```

**장점:**
- ✅ **서버 사이드 검증**: 서버에서 추가 검증 가능
- ✅ **보안 강화**: 민감한 로직을 서버에서 처리
- ✅ **추가 비즈니스 로직 용이**: 회원가입 후 추가 작업 (예: 초기 데이터 생성)
- ✅ **일관성**: 다른 Server Actions와 일관된 패턴
- ✅ **타입 안정성**: FormData 타입 체크

**단점:**
- ⚠️ **Supabase 권장 방식 아님**: 공식 문서는 클라이언트 방식을 권장
- ⚠️ **세션 관리 복잡**: 쿠키 설정을 수동으로 처리해야 할 수 있음
- ⚠️ **OAuth 호환성**: OAuth는 클라이언트 리다이렉트 필요
- ⚠️ **에러 처리 복잡**: Server Action 에러를 클라이언트에서 처리해야 함
- ⚠️ **리다이렉트 제한**: Server Action에서만 리다이렉트 가능 (useFormState 필요)

## Supabase 공식 권장사항

### Supabase 공식 문서

**Supabase는 클라이언트 사이드 인증을 권장합니다:**

1. **세션 관리 자동화**
   - Supabase가 쿠키를 자동으로 관리
   - `@supabase/ssr` 패키지가 서버/클라이언트 동기화

2. **OAuth 호환성**
   - OAuth는 클라이언트 리다이렉트 필요
   - Server Action과 혼용 시 복잡도 증가

3. **실시간 업데이트**
   - `onAuthStateChange`로 실시간 세션 업데이트
   - Server Action에서는 불가능

### Next.js App Router + Supabase 패턴

**권장 패턴:**
```typescript
// 클라이언트 컴포넌트에서 인증 처리
'use client';
const supabase = createBrowserSupabaseClient();
await supabase.auth.signUp({ email, password });

// 서버 컴포넌트에서 세션 확인
const supabase = await createServerSupabaseClient();
const { data: { user } } = await supabase.auth.getUser();
```

## 하이브리드 접근 방식 (권장)

### 권장: 클라이언트 인증 + Server Action 보조

**핵심 원칙:**
- ✅ **인증 자체는 클라이언트에서 처리** (Supabase 권장)
- ✅ **추가 비즈니스 로직은 Server Action 사용**
- ✅ **회원가입 후 초기화는 Server Action**

**구현 예시:**

```typescript
// 1. 클라이언트 컴포넌트: 인증 처리
'use client';
// src/components/auth/sign-up-form.tsx
export function SignUpForm() {
  const handleSubmit = async (e: React.FormEvent) => {
    const supabase = createBrowserSupabaseClient();
    
    // Supabase 인증 (클라이언트)
    const { data, error } = await supabase.auth.signUp({
      email,
      password,
      options: { data: { full_name: fullName } },
    });

    if (error) {
      toast.error(error.message);
      return;
    }

    // 회원가입 성공 후 추가 작업 (Server Action)
    if (data.user) {
      await initializeUserAccount(data.user.id);
    }

    toast.success('Check your email for the confirmation link!');
  };
}

// 2. Server Action: 추가 비즈니스 로직
'use server';
// src/app/actions/auth.ts
export async function initializeUserAccount(userId: string) {
  const supabase = await createServerSupabaseClient();
  
  // 추가 초기화 작업
  // 예: 기본 조직 생성, 초기 설정 등
  await supabase.from('user_settings').insert({
    user_id: userId,
    // ...
  });
}
```

### 구현 예시

**1. 회원가입 (하이브리드):**

```typescript
// components/auth/sign-up-form.tsx
'use client';

export function SignUpForm() {
  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    
    // 1. 클라이언트: Supabase 인증
    const supabase = createBrowserSupabaseClient();
    const { data, error } = await supabase.auth.signUp({
      email,
      password,
      options: { data: { full_name: fullName } },
    });

    if (error) {
      toast.error(error.message);
      return;
    }

    // 2. Server Action: 추가 초기화 (선택적)
    if (data.user && !data.session) {
      // 이메일 확인 필요 시 초기화는 나중에
      toast.success('Check your email for the confirmation link!');
    } else if (data.user && data.session) {
      // 즉시 로그인된 경우 초기화
      await initializeUserAccount(data.user.id);
      router.push('/dashboard');
    }
  };
}

// app/actions/auth.ts
'use server';

export async function initializeUserAccount(userId: string) {
  const supabase = await createServerSupabaseClient();
  
  // 기본 조직 생성 (v5.0 요구사항)
  const { data: org } = await supabase
    .from('organizations')
    .insert({ name: 'My Organization' })
    .select()
    .single();

  if (org) {
    // 멤버십 생성
    await supabase.from('memberships').insert({
      user_id: userId,
      entity_id: org.id,
      entity_type: 1, // ORGANIZATION
      permissions: 31, // ORG_OWNER 권한
    });
  }
}
```

**2. 로그인 (하이브리드):**

```typescript
// components/auth/sign-in-form.tsx
'use client';

export function SignInForm() {
  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    
    // 1. 클라이언트: Supabase 인증
    const supabase = createBrowserSupabaseClient();
    const { data, error } = await supabase.auth.signInWithPassword({
      email,
      password,
    });

    if (error) {
      toast.error(error.message);
      return;
    }

    // 2. Server Action: 구독 상태 확인 및 리다이렉트
    if (data.user) {
      const result = await checkAndRedirect(data.user.id);
      if (result.redirect) {
        router.push(result.redirect);
      } else {
        router.push('/dashboard');
      }
    }
  };
}

// app/actions/auth.ts
'use server';

export async function checkAndRedirect(userId: string) {
  const supabase = await createServerSupabaseClient();
  
  // 사용자의 활성 엔티티 조회
  const { data: memberships } = await supabase
    .from('memberships')
    .select('entity_id, entity_type')
    .eq('user_id', userId)
    .limit(1)
    .single();

  if (!memberships) {
    return { redirect: '/onboarding' };
  }

  // 구독 상태 확인
  const { data: subscription } = await supabase
    .from('entity_subscriptions')
    .select('status')
    .eq('entity_id', memberships.entity_id)
    .eq('entity_type', memberships.entity_type)
    .single();

  if (!subscription || subscription.status !== 1) { // ACTIVE
    return { redirect: '/billing/suspended' };
  }

  return { redirect: null };
}
```
